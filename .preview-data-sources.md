The restored preview database is non-production test data. It uses publicly available MangaDex-referenced title metadata and cover-art search assets solely to repopulate the temporary NyaScans testing environment after the local sandbox state was reset.

- MangaDex public API collection retrieved on 2026-08-14: `https://api.mangadex.org/manga?limit=12&includes[]=cover_art&includes[]=author&includes[]=artist&order[followedCount]=desc&contentRating[]=safe&contentRating[]=suggestive`
- The response included the MangaDex record for **Solo Leveling** (`32d76d19-8a05-4db0-9fc2-e0b0648fe9d0`) and other public discovery records.
- The supplied series URL remains recorded as MangaDex metadata for **The Discarded Mercenary Wants to Live Freely**: `https://mangadex.org/title/9800fcce-b7af-46d7-aefc-b9364ee75b55/suterare-youhei-wa-jiyuu-kimama-ni-ikitai`.
- Test cover files were placed only in the local temporary preview under `public/art/seed/`; they are not part of the source release or a production asset migration.
